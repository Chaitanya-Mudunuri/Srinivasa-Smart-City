# Srinivasa Smart City

Official website and digital project portal for **Sri Srinivasa Smart City**, a premier plotted layout in Jaggampeta, East Godavari District, Andhra Pradesh. Developed by **Mudunuri Seetharamaraju** and **Mudunuri MuraliKrishnamRaju**.

- **Custom Domain:** [srinivasa.smartcity.mudunuri.co.in](https://srinivasa.smartcity.mudunuri.co.in)
- **RERA Registration:** P04180171449

## Deployment Setup
Built with Next.js (Static Export), Tailwind CSS, and React Three Fiber. Configured for automatic deployment to GitHub Pages with a CNAME record.
